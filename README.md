# 都道府県の人口動向アプリ

総務省「人口推計」のデータを使い、都道府県別の人口推移を可視化し、機械学習で翌年の人口増減率を予測するWebアプリです。

地域について学ぶ学生や、地域ごとの人口変化に関心がある人が、人口動向を把握するために作成しました。

## 公開URL

- アプリ：https://population-app-hgpzcemdrzkp6wpvtjr5us.streamlit.app/
- GitHub：https://github.com/9944kojiwork-oss/population-app

## 使い方

1. アプリのURLを開きます。
2. 調べたい都道府県を選択します。
3. 人口推移・前年比増減率・データ表を確認します。
4. 「2021年を予測する」ボタンを押すと、予測人口増減率と予測人口が表示されます。

利用者がコードやコマンドを実行する必要はありません。

## 使用データ

- 作成機関：総務省統計局
- 統計名：人口推計
- データ：長期時系列データ 第5表「都道府県別人口（各年10月1日現在）－総人口、日本人（2000年～2020年）」
- 入手先：[政府統計の総合窓口 e-Stat](https://www.e-stat.go.jp/stat-search/files?tclass=000001039703&cycle=0&layout=datalist)
- 使用ファイル：`05k5-5.xlsx`
- 対象：47都道府県の総人口
- 期間：2000～2020年
- 単位：千人

「総人口」の2つのシートを結合し、重複する2015年を1件に整理しています。前年比増減率は、掲載された人口から計算しています。

本アプリのグラフ・増減率・機械学習による予測は、上記データを加工して作成したものです。総務省が公表する公式の予測ではありません。

データの利用に際しては、[e-Statの利用規約](https://www.e-stat.go.jp/terms-of-use)および提供元の利用上の注意をご確認ください。本リポジトリ独自の条件で元データを再ライセンスするものではありません。

## 使用した機械学習モデル

scikit-learnのRidge回帰を使用しています。

### 入力と予測対象

- 入力：予測対象年の1年前・2年前・3年前の人口増減率
- 予測対象：翌年の人口増減率（％）

47都道府県のデータをまとめて学習します。入力値を`StandardScaler`で標準化し、Ridge回帰に渡す構成です。正則化の強さは`alpha=1.0`としています。

予測人口は、次の式で計算します。

予測人口 ＝ 前年の人口 ×（1 ＋ 予測増減率 ÷ 100）

### 学習・推論の実装

学習・評価・推論のコードは、`app.py`に含まれています。

- `build_models()`で特徴量を作成し、モデルを学習・評価します。
- `fit()`で学習し、`predict()`で推論します。
- 学習したモデルは`st.cache_resource`でメモリ上に保持します。
- 公開先のStreamlitアプリ内でモデルを実行します。

学習済みモデルを別ファイルから読み込む構成ではなく、アプリ起動後の初回処理で学習する構成です。外部AI APIに推論を依頼していません。

## 評価方法

時系列に沿って、次のようにデータを分けています。

- 学習：予測対象年が2017年までのデータ
- テスト：予測対象年が2018～2020年のデータ

予測対象年より後の情報を入力に使わず、標準化も学習データだけで調整します。

評価指標には、人口増減率の平均絶対誤差（MAE）を使用します。単位はパーセントポイントで、小さいほど予測誤差が小さいことを意味します。

比較対象として、「前年と同じ人口増減率が続く」とする単純な予測方法も評価しています。各方法の評価値はアプリ内の「モデルの評価」に表示されます。

評価後、予測用モデルを2020年までの利用可能なデータで学習し、2021年の予測に使用します。

## 工夫した点

- 都道府県を選ぶだけで、人口推移と前年比増減率を確認できる画面にしました。
- 人口規模の異なる都道府県を扱うため、予測対象を人口そのものではなく増減率としました。
- 古い年で学習し、新しい年で評価することで、予測時点を意識した評価にしました。
- 単純な予測方法と比較し、機械学習を使った効果を確認できるようにしました。
- データの読み込みとモデルをキャッシュし、画面操作のたびに同じ処理を繰り返さないようにしました。

## つまずいた点と解決方法

公開先でExcelファイルを読み込む際、`openpyxl`を読み込めずエラーになりました。

PC上にインストールしたライブラリは、公開先へ自動的に引き継がれないことを確認しました。公開先にも必要なライブラリがインストールされるように`requirements.txt`を確認・修正し、再デプロイ後に動作を確認しました。

## 注意点・限界

- データの収録期間は2000～2020年です。最新の人口動向を表示するアプリではありません。
- 予測対象は2021年です。現在から見た将来予測ではなく、過去のデータを用いた学習用の推定です。
- 元データが千人単位で丸められているため、人口増減率や予測人口も概算です。
- 過去の増減率のみを入力にしており、出生・死亡・転入転出や政策などの要因を個別にモデル化していません。
- この予測だけから、人口変化の原因を判断することはできません。
- 元データには国勢調査に基づく補間補正が含まれます。評価は後から整備されたデータを使うもので、当時入手できたデータだけによる予測の再現ではありません。

## PCでの実行方法

Python 3.12を使用した開発手順です。

リポジトリをダウンロードし、そのフォルダで以下を実行します。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

起動後、ブラウザで `http://localhost:8501` にアクセスしてください。
