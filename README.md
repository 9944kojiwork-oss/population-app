# population-app
都道府県の人口推移と機械学習による人口増減率予測

総務省「人口推計」のデータを使い、都道府県別の人口推移を可視化し、機械学習で翌年の人口増減率を予測するWebアプリです。

地域について学ぶ学生や、地域ごとの人口変化に関心がある人が、人口動向を把握するために作成しました。

## 公開URL

- アプリ：https://population-app-hgpzcemdrzkp6wpvtjr5us.streamlit.app/
- GitHub：https://github.com/9944kojiwork-oss/population-app

## 使い方

1. アプリのURLを開きます。
2. 調べたい都道府県を選択します。
3. 人口推移・前年比増減率・データ表を確認します。
4. 「2021年を予測する」ボタンを押すと、予測人口増減率と予測人口が表示されます。

利用者がコードやコマンドを実行する必要はありません。

## 使用データ

- 作成機関：総務省統計局
- 統計名：人口推計
- データ：長期時系列データ 第5表「都道府県別人口（各年10月1日現在）－総人口、日本人（2000年～2020年）」
- 入手先：[政府統計の総合窓口 e-Stat](https://www.e-stat.go.jp/stat-search/files?tclass=000001039703&cycle=0&layout=datalist)
- 使用ファイル：`05k5-5.xlsx`
- 対象：47都道府県の総人口
- 期間：2000～2020年
- 単位：千人
